## tDocs v3.1.5

### Changed

- **Left sidebar, simplified:** Storage, Media, and Tools sections now start collapsed, so the sidebar shows just the Menu items plus three section headers — no more scrolling a 15-item nav. Click a header to expand it; the state is saved, so it survives reloads.
- **Hide/unhide fixed properly:** section collapse is now class-based instead of inline styles, and switching tabs (including from Quick Access or search) auto-expands the section holding the active item — the active page's menu entry can no longer sit hidden inside a collapsed section.

### Added

- **Drag & drop in All Files:** drag a file card (grid view) or file row (list view) onto a folder card or folder row to move it there. It uses the existing bulk-move endpoint, so dropping a selected file moves the whole selection; files already inside the target folder are skipped, and a toast confirms how many files moved. Desktop browsers only — HTML5 drag & drop does not exist on touch screens.
