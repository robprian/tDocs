### Fixed
- `tdocs update` via apt no longer prints "Download is performed unsandboxed
  as root ... couldn't be accessed by user '_apt' (13: Permission denied)".
  The temporary download directory and package file are now readable by
  apt's sandbox user (0755 / 0644 instead of 0700 / 0600).
- `tdocs update` now restarts the `tdocs` service automatically when it is
  running, instead of only printing "Restart the service if running". A
  service that is not running is left alone, and a failed restart is
  reported as a warning without failing the already-successful update.
