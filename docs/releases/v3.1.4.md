## tDocs v3.1.4

### Fixed

- **Service stays down after `tdocs update` (deb):** the old package's `prerm` ran `systemctl disable --now tdocs.service` on every upgrade, and the updater only checked `is-active` *after* apt had already stopped the service — so it printed "not running, no restart needed" while leaving a previously running service stopped *and* disabled. The updater now captures the service state (active + enabled) *before* the install and restores exactly that state afterwards; the `.deb` `prerm` no longer stops the service on upgrade (only on real removal), and `postinst` re-enables + restarts the service on upgrade of an already-configured install — which also self-heals the v3.1.3 → v3.1.4 transition, where the old updater binary is still the one running.
- If your service is currently down after the v3.1.3 update, recover it once with: `sudo systemctl enable --now tdocs` (then `systemctl status tdocs` should show it active again).

### Changed

- **Sidebars match the new design:** left nav is now the full reference menu (Overview, All Files, Shared Links, Favorites, Recent, Trash; Storage: Sync Center, Snapshots, Backups; Media: Documents, Images, Videos, Music; Tools: Categories, Settings) with collapsible sections. Every item goes somewhere real: Recent scrolls to the Overview recent panel, Backups opens Snapshots, Documents opens Drive filtered to documents, Categories opens Drive at root. The Overview right rail is now exactly the four new-design cards: Telegram Accounts, Multi-account Mirror, Synchronization (last sync, status, files indexed, measured sync speed from real sync runs), and Storage Usage (donut + per-category legend from the real stats breakdown). The old rail cards (Storage gauge, Telegram Cloud, Upload dropzone, Recent Activity, File Categories) are removed from Overview — upload is still one click away from the hero button and All Files, activity still lives in the audit log.
- Honest gaps vs the reference screenshot: Tags and File Requests appear in the reference sidebar but have no feature or backend in tDocs at all, so they are intentionally not menu items (a button to nowhere would be worse). Pending Files has no backend source either, so its row shows "—" instead of an invented 0. The Mirror card keeps the accurate outbound wording ("copied to backup accounts") rather than the screenshot's inbound phrasing, because backup channels are never merged into the library catalog.
