## v3.1.3

### Fixed

- **Dashboard matches the reference layout, nothing clipped.** The Overview
  page no longer hides My Folders, Recent Activity or the hero art on
  short desktop screens: panels flow naturally and the page scrolls
  cleanly instead of clipping content. The Storage gauge center now shows
  only the used size plus "used"; "Unlimited" lives in the legend as
  "Capacity", and the Storage Used / sidebar texts read "of Unlimited".
  Recent Files gains a Type column (Image/Video/Audio/PDF or extension).

### Added

- **Overview Telegram Accounts card.** The right rail now shows every
  account like the reference design: avatar initials, Primary/Mirror
  badges, phone number, last-synced time and file count, a per-account
  menu (Backup Now / Remove) and a + Add shortcut to the Sync Center.
  The "Multi-account Mirror" toggle below it is real: when on, every
  new upload is automatically copied to all ready backup accounts in
  the background (manual Backup Now always works, toggle on or off).
  Note: the toggle copies library files *to* backup accounts; it does
  not merge backup channels back into the library catalog.

- **Multi-Telegram accounts (backup targets).** Additional phone numbers
  can be registered from the Sync Center, paired through the same browser
  wizard, and used as backup storage: "Backup Now" streams every library
  file that is not yet copied to that account's own "tDocs Vault"
  channel (already-copied files are skipped, progress is polled live).
  Each account owns its own encrypted session, authorization flag and
  storage channel keys, so pairing a second number can never overwrite
  the primary account's session or channel. Backup channels never merge
  into the main catalog, so message IDs from different channels cannot
  collide. Google Drive support is intentionally not included in this
  release.
